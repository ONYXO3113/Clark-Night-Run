Comment lire ce livre

Règles

  1. index.html est la première page. Elle est différente des suivantes : c'est la couverture.
  2. Depuis la couverture, vous choisissez un véhicule. Ce choix compte : il ouvre ou verrouille certains passages.
  3. Chaque page de l'aventure présente le même gabarit : une image, un texte, puis une liste de liens. Chaque lien est une décision.
  4. Cliquer sur un lien applique ses effets (alerte, réputation, secrets, confiance) puis ouvre la page suivante.
  5. Un choix marqué VERROUILLÉ n'est pas accessible : le livre explique pourquoi juste dessous.

Mini-jeu : le barrage

Le chapitre Le barrage remplace la liste de choix par un mini-jeu de tir. Des silhouettes de policiers avancent vers toi : clique sur leurs gyrophares pour les faire reculer. Si l'un d'eux franchit la ligne rouge avant la fin du chrono, tu perds. Tiens vingt secondes pour gagner. Le jeu est écrit en JavaScript, dans le fichier game.js, et il fonctionne hors ligne.

La progression est enregistrée dans le localStorage de votre navigateur, sur cet ordinateur et ce navigateur uniquement. Elle n'est envoyée nulle part. Pour repartir de zéro, utilisez le bouton Effacer ma progression de la page des fins.

Commandes

  • Clavier — Tab pour suivre les liens, Entrée pour valider.
  • Souris ou tactile — tous les liens sont cliquables, aucun geste bizarre n'est demandé.
  • Impression — Ctrl+P fonctionne : la mise en page s'adapte au papier.
